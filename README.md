# Ranking Program Python
### A program designed for ranking a list of items manually using a "this or that" system.
## What Is This Project?
This project is the result of multiple iterations attempting to help me rank my favorite songs in order. Initial versions used a modified merge sort whereas this version uses a modified binary search. I have developed this project occasionally during both a-levels and university. Version 1.1 improves code readability alongside adding multi-line text. I will likely continue to develop this project when I next want to rank further songs.
## How To Use
Before running the program, paste the list to be sorted into the 'lis' variable. Currently, the list to be sorted uses a placeholder of letters 'a' through to 'f'. When running the program, select the item you prefer (want to be ranked highest) between the two options. When the window closes, selection is finished and the resulting order will be printed.
